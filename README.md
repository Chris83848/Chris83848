## Featured Projects

### ⚾ [MLB Plate Approach Mining](https://github.com/Chris83848/MLB-Data-Mining)
A K-Means clustering and anomaly detection implementation on qualified MLB hitters to uncover plate discipline archetypes and identify outliers. It was built with Python, scikit-learn, and pandas, and runs interactively via Binder.

### ♟ [Sudoku Solver](https://github.com/Chris83848/Sudoku-Solver)
A fully packaged Java/JavaFX desktop application with symmetric puzzle generation, a complete interactive UI for solving, and two live-animated solvers (recursive backtracking and human-technique reasoning). The final release required a full year of solo development.

### 🌐 [Web Crawler & BM25/TF-IDF Search](https://github.com/Chris83848/Web-Crawler-BM25)
An end-to-end information retrieval pipeline, containing a breadth-first web crawler, inverted index, and BM25/TF-IDF ranking. The sample crawl space collected 292 documents totaling 816,892 words.

### 🍽 [Restaurant Management Software System](https://github.com/Chris83848/Restaurant-Management-Software-System)
A role-based Java Swing desktop app for restaurant staff to manage tables, place orders, and dispatch to a kitchen queue. It was designed by a team of five, with me serving as the project lead.

### ♟ [Chess Time Management Graphs](https://github.com/Chris83848/Chess-Time-Management)
An ongoing personal R/ggplot2 project tracking clock usage across over-the-board tournament games, visualizing time management move-by-move against an ideal pace line.
